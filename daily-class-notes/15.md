# Github Reusable Workflows 
* A reusable workflow is a complete workflow file that cab be called by other workflows. just like a funciton in programming.
* Image we have 6 microservices for our product. Each microservice has its own repo for ci/cd pipeline . Every pipeline does the same things
```
checkout -> setup-java -> Test -> Scans -> Build -> Docker-build-push -> deploy to dev -> deploy to test -> deploy to stage -> deploy to prod
```
* without reusballe workflows
    * service-1: repo > ci.yaml > 350 lines of code 
    * service-2: repo > ci.yaml > 350 lines of code 
    * service-3: repo > ci.yaml > 350 lines of code 
    * ....
* New scans code should be again implemente dacross all microservices 



* with reusable workflows
* shared repo > resuable-workflow.yaml (350 lines of code)
    * service-1: repo > caller.yaml > 10 lines of code just to call the shared workflow
    * service-2: repo > caller.yaml > 10 lines of code just to call the shared workflow
    * service-3: repo > caller.yaml > 10 lines of code just to call the shared workflow
