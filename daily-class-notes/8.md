* Outputs

* In a workflow, jobs or steps often needs to share data with each other . 
* we have 2 ways to share data:
    * env:          -> Static values defined the yaml files
    * $GITHUB_ENV   -> dynaic values shared b.w steps in the same job 
* but what if you need to pass value from one job to other job ? 
* this is wehere outputs comes in 
    * step outputs  -> pass data b/w steps in the same job
    * job outputs   -> pass data b/w different JOBS 
* Basic example
```yaml
- name: MyStep
  id: my-steps # id is required 
  run: echo "name=siva" >> $GITHUB_OUTPUT
```
