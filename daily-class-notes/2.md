## What is CI/CD ?
* A typical s/w delivery flow looks like this , 
Developers writes the code > Code is review > Application should be build > Tests are executed > Application should be deplpyed
* If Every stage is perfomed manually, the process becomes slow and repetitive and error-prone.
* CI/CD helps us automate this s/w delivery process.


## CI ?
* CI stands for Continuos Integration
* CI is the practise of frequent;ly adding code changes to a shared repo and automatically vlaidating those changes. 
* Whenever a dev pushes a code , the CI process can automatically 
    * Download the latest source code 
    * install dependencies 
    * compile or build the applicatin
    * Unit test cases 
    * Code quality check 
    * Problem identify.
Main GOal: 
Integrate code frequently, and identify probelen as early as possible. 
* CI Server: jenkins, github actions , cloud build (serverless)

## CD
* CD can be Continuos Delivery or Continuos Deployment.
* Both start afte the CI process succesfully validates the application.


### Continuos Delivery
CD means every succesful code changes is automaticaly built, tested and usuually deployed to lower env, whule remaininign readu for prod env thrpugh a mainall approval. 
THe process may automatically
* Build the applciation package
* Create the docker image
* Push the image to registry 
* Deploy the application to dev, test or stage env 
`Keep the application ready for prodcution deployment at any time `


### Continuos Deployment
Continuos Deployment goes one step further
when all the validation are passed the app is automtically deploye dto production without manual approval.



### Where does github actions fit ? 
* Github actions is an automation platform that can implement CI/CD workflows directly inside github.


### Summarise:
* CI: Integrate build and test the code frequently 
* Continuos Delivery: Keep the applciation ready for deployment 
* Continuos Deployment: Automatically deploy success chnages to production. 
* Github actions: Tool used to automate those ci/cd activities .
