## Dynamic Variables:
`$GITHUB_ENV` is a special file provided by github actions that lets you est the environmentala variables at run time
* difference 
   * `env:`          -> static   -> Values are known before the workflow starts
   * `$GITHUB_ENV`   -> Dynamic  -> Values are computed during the workflow run.
